### Task 1
### Exception Handling (try, catch finally)
#### (English) 
Write a program that asks the user for two numbers and prints the result of dividing them.                                                
However, if the user enters incorrect data (for example, letters instead of numbers), the program must                                 
handle this and print an error message instead of the division result.                                                   

#### (Russian)
Напишите программу, которая запрашивает у пользователя два числа и выводит результат их деления.                                                                        
Однако, если пользователь вводит некорректные данные (например, буквы вместо чисел), программа должна                                              
обрабатывать это и выводить сообщение об ошибке вместо результата деления.                                             

#### (Tajik)
Барномае нависед, ки аз корбар ду ададро талаб мекунад ва натиҷаи тақсими онҳоро чоп мекунад.                                    
Аммо, агар корбар маълумоти нодуруст ворид кунад (масалан, ба ҷои рақамҳо, ҳарфҳо), барнома бояд                              
инро идора кунад ва ба ҷои натиҷаи тақсимот паёми хаторо чоп кунад.   

### Datetime
### Task 1
#### (English)
Write a program that displays the current date and time in the format "YYYY-MM-DD HH:MM:SS".

#### (Russian) 
Напишите программу, которая выводит текущую дату и время в формате "ГГГГ-ММ-ДД ЧЧ:ММ:СС".

#### (Tajik)
Барномаеро нависед, ки сана ва вақти ҷорӣро дар формати "СЖИ-АА-ДД СШ:ДМ:СС" нишон медиҳад.

### Task 3
#### (English)
Write a program that prompts the user for a date in the format "YYYY-MM-DD" and displays the number of days that have elapsed since that date until today.

#### (Russian)
Напишите программу, которая запрашивает у пользователя дату в формате "ГГГГ-ММ-ДД" и выводит количество дней, прошедших с этой даты до сегодняшнего дня.

#### (Tajik)
Барномаеро нависед, ки аз Истифодабаранда  санаро дар формати "YYYY-MM-DD" талаб мекунад ва шумораи рӯзҳоеро, ки аз ин сана то имрӯз гузаштаанд, нишон медиҳад.


### Enum
#### Task 4
#### (English)
Write a program that prompts the user for a month number (from 1 to 12) and displays the month name using an enumeration.

#### (Russian)
Напишите программу, которая запрашивает у пользователя номер месяца (от 1 до 12) и выводит название месяца с помощью перечисления (enum).

#### (Tajik)
Барномаеро нависед, ки ба Истифодабаранда рақами як моҳро (аз 1 то 12) пешниҳод мекунад ва номи моҳро бо истифода аз enum нишон медиҳад. 

### Task 5
#### (English)
Write a program that prompts the user for a color name (red, green, blue) and displays its RGB code using an enumeration.

#### (Russian)
Напишите программу, которая запрашивает у пользователя название цвета (красный, зеленый, синий) и выводит его код в формате RGB с помощью перечисления (enum).

#### (Tajik) 
Барномаеро нависед, ки аз Истифодабаранда номи рангро (сурх, сабз, кабуд) мепурсад ва рамзи RGB-и худро бо истифода аз enum намоиш медиҳад.
